Privacy Policy

Last updated: October 12, 2026

"AliExpress Orders Report" ("the extension") is a browser extension that helps you export your AliExpress order history to Excel (XLSX) or CSV files.

How the Extension Works

When you click "Export Orders," the extension reads order details directly from the AliExpress Orders page that is currently open in your browser. This data is processed on your device and used to generate the Excel or CSV file that is downloaded to your computer.

Optional Data Collection

The extension offers an optional feature to contribute anonymous product data to help build a price history database. This feature is disabled by default and requires your explicit consent.

If you choose to participate, we collect:

  • Product URLs (links to AliExpress product pages)
  • Product names
  • Order prices and currency
  • Order dates

We NEVER collect:

  • Order numbers or transaction IDs
  • Your identity, email, or account information
  • Shipping addresses or payment details
  • Quantities purchased
  • IP addresses (not logged on our servers)

Your Choices

Data sharing is completely optional:

  • You are asked once when you first use the extension
  • The default option is "No" (local export only)
  • You can change your preference at any time via the Settings menu (gear icon)
  • If you opt out, no data is ever sent to our servers

How We Use Collected Data

If you opt in, the anonymous product data is used solely to:

  • Build a price history database for AliExpress products
  • Track price trends over time
  • Potentially help users find better deals (future feature)

We do not sell, trade, or share this data with third parties for advertising or marketing purposes.

Data Retention

Collected product data (if you opt in) is stored indefinitely to maintain price history. Since no personal identifiers are collected, this data cannot be linked back to you.

Data Security

All data transmissions use HTTPS encryption. Our servers follow industry-standard security practices.

Permissions

The extension requests the following permissions:

  • activeTab - Read the current AliExpress Orders page
  • scripting - Extract order data from the page
  • downloads - Save the exported file to your computer
  • storage - Remember your data sharing preference
  • host_permissions (aliexpress.com) - Only operates on AliExpress pages

Changes to This Policy

If this policy changes, the updated version will be posted on this page. Significant changes to data collection practices will prompt a new consent request in the extension.

Contact

If you have questions about this privacy policy, contact us at: Extension@umxir.com
